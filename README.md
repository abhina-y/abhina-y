## ⭐ Featured Projects

### 🏦 Ledger-Based Banking System
> A backend-focused banking application built around ledger-based, double-entry accounting.

Implements ACID-compliant transactions and idempotent fund transfers to keep financial records consistent and auditable. Secure RESTful APIs are protected with JWT authentication, bcrypt password hashing, session handling, and token blacklisting, alongside account management, transaction processing, balance tracking, and automated email notifications.

**Tech:** `Node.js` `Express.js` `MongoDB` `JWT` `bcrypt`

[View Repository →](https://github.com/abhina-y/ledger-based-banking-system)

---

### 🩺 MediMeet — Telemedicine Platform
> A full-stack telemedicine platform connecting patients and doctors through a modern web application.

Features role-based access control (Admin, Doctor, Patient) with dedicated dashboards and custom onboarding flows, real-time video consultations, and a credit-based payment system built on atomic database transactions covering booking deductions, refunds, and subscription allocations with a full audit ledger. Also includes an AI-powered symptom-analysis chatbot and a secure doctor payout system with dynamic fee calculation and duplicate-request prevention.

**Tech:** `Next.js` `React` `PostgreSQL` `Prisma` `Clerk` `Groq AI`

[View Repository →](https://github.com/abhina-y/medimeet)

---

### 🤖 AI Job Preparation Platform
> A full-stack, AI-powered platform for resume analysis and interview preparation.

Analyzes resumes to identify skill gaps and generate role-specific technical and behavioral interview questions using an LLM, along with resume-to-job-description matching and ATS-focused improvement recommendations. Includes JWT-based authentication, resume upload/parsing, and automated ATS-optimized PDF resume generation.

**Tech:** `React.js` `Node.js` `Express.js` `MongoDB` `Mongoose` `JWT` `Gemini AI`

[View Repository →](https://github.com/abhina-y/ai-job-preparation-platform)

---

### 🧠 Mental Health Score Predictor
> A machine learning project predicting student mental health scores from lifestyle and demographic data.

Built an end-to-end regression pipeline covering data preprocessing, feature engineering (country grouping, scaling, log transformation, ordinal and one-hot encoding), and model development with a tuned Random Forest, evaluated using R², MAE, and RMSE. The trained model is served through a FastAPI REST API with Pydantic validation for real-time inference. *(Research/analytical project — not a diagnostic or clinical tool.)*

**Tech:** `Python` `Scikit-learn` `FastAPI` `Pandas`

[View Repository →](https://github.com/abhina-y/mental-health-score-predictor)

---

### 🔬 Brain Tumour Detection
> A computer vision project for classifying brain MRI scans using deep learning.

Applies image preprocessing and data augmentation to MRI scans, with transfer learning on MobileNetV2 for classification, built using TensorFlow/Keras and OpenCV. Includes model evaluation and a Streamlit application for interactive testing. *(A machine learning research/project application — not a certified medical diagnostic system.)*

**Tech:** `TensorFlow` `Keras` `MobileNetV2` `OpenCV` `Streamlit`

[View Repository →](https://github.com/abhina-y/brain-tumour-detection)
